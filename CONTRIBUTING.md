# Contributing

Thanks for taking a look. This is a portfolio project, but suggestions and fixes are welcome.

1. Fork the repository and create a branch from `main`.
2. Follow the setup steps in the README.
3. Keep to the design guide in `docs/DESIGN.md`, including the writing rules.
4. Run `npm test` before opening a pull request.
5. Describe what you changed and why in the pull request.

Every pull request runs the tests on GitHub Actions and gets a Vercel preview.
